# 📊 Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on Exploratory Data Analysis (EDA) using Python to analyze sales, inventory, and demand-supply datasets. It includes data visualization, statistical analysis, and inventory optimization to identify product shortages and surpluses.

## 🎯 Objectives
- Analyze sales and inventory datasets.
- Understand inventory quantity distributions.
- Visualize demand vs. supply for different products.
- Identify products with inventory shortages and surpluses.
- Calculate optimal inventory levels using optimization techniques.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn

## 🔍 Key Analysis

### 1. Sales Data Analysis
- Load and explore sales data.
- Handle parsing errors while reading CSV files.

### 2. Inventory Analysis
- Analyze product stock quantities.
- Visualize inventory distribution using histograms.
- Calculate optimal inventory levels using SciPy optimization.

### 3. Demand vs. Supply Analysis
- Compare product demand and supply.
- Visualize comparisons using bar charts.
- Identify products with excess supply and shortages.

## ⚙️ Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/your-username/Exploratory-Data-Analysis.git
```

2. Navigate to the project directory:

```bash
cd Exploratory-Data-Analysis
```

3. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn
```

4. Launch Jupyter Notebook:

```bash
jupyter notebook
```

5. Open `EDA.ipynb` and run the cells.
